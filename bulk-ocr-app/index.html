Bulk OCR Studio Guide

How to use this app for Downstream LLMs & RAG:

  • Consistent Output Naming: All ZIP, TXT, JSON, and JSONC exports automatically follow the format `batch-yyyy-mm-dd_hh-mm[am/pm]` based on system time.
  • Low-Confidence Review Wizard: Automatically isolates words with confidence < 75%, letting you review and correct them word-by-word like Adobe Acrobat.
  • RegEx Search: Toggle the `.* RegEx` button in the search bar to query extracted text using regular expressions.
  • IndexedDB Persistence: Work survives page refreshes and never freezes your browser.
