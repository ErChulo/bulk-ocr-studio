Bulk Document Studio Guide & Formats

Supported File Formats & Parsers:

  • Images (PNG, JPG, WEBP, BMP, TIFF, GIF): Processed via Tesseract.js OCR.
  • PDF Documents (.pdf): Automatically rendered page-by-page into high-res images for per-page OCR.
  • Excel Spreadsheets (.xlsx, .xls): Instantly parsed table-by-table into clean formatted text.
  • CSV Files (.csv): Parsed and formatted into structured tabular text.
  • Text & Markdown (.txt, .md): Direct text extraction with zero overhead.
  • IndexedDB Persistence: Powered by Dexie.js so your work never vanishes and apps never freeze.
  • Downstream JSONC: Export or preview structured JSON with comments for RAG and downstream modules.
