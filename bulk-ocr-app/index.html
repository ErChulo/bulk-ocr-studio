Bulk OCR Studio Guide & Data Storage

Where are the inferred text results stored?

Because this application runs 100% client-side in your browser with zero server calls, all inferred text results are stored securely in your browser's active memory (JavaScript RAM state via `fileQueue`).

Key Architectural Highlights & JSONC Export:

  • JSONC Support: Export your batch results to JSON with comments (`.jsonc`), which injects detailed metadata, extraction timestamps, word counts, and comments explaining each page's status directly into the file for downstream modules!
  • Per-Page Processing: Images count as 1 page, and multi-page PDFs are automatically split and rendered page-by-page.
  • Live Inspection & Editing: Click any item in the grid to inspect the original page side-by-side with the inferred text and make manual edits instantly.
  • Privacy & Safety: Nothing leaves your computer. Closing or refreshing your browser tab clears active memory.
