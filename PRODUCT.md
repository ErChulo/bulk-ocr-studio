# PRODUCT.md

## Product Overview
**Bulk OCR Studio** is a 100% client-side batch optical character recognition application designed for high-throughput, privacy-first text extraction from local directories, images, and multi-page PDFs.

## Primary Use Case & Downstream Consumers
- **Downstream Modules**: The application serves as a robust data pipeline producing structured **JSONC (JSON with Comments)** output for downstream ingestion modules, RAG knowledge bases, and document indexing pipelines.
- **Audience**: Data engineers, researchers, and developers requiring client-side batch OCR with zero data leakage or server uploads.
- **Brand Personality**: Utilitarian, precise, highly polished, dark-mode focused, lightning-fast, and transparent.
